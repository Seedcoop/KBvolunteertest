# 프로젝트 후속 온라인 미팅

현장 워크숍에서 만든 프로젝트 기획을 두 차례 온라인 미팅으로 이어갑니다.

## 1차 온라인 미팅

`meeting1.html`

프로젝트의 핵심 사실과 활동안을 다시 확인하고, 담당자·날짜·남길 기록이 있는 실행 약속으로 정리합니다. 기존 워크숍 기록을 같은 브라우저에서 바로 불러오거나 JSON으로 옮길 수 있습니다.

저장 파일:

- `{팀명}_1차미팅.json`: 2차 미팅에서 이어 쓰는 작업 파일
- `{팀명}_1차실행안.html`: 1차 미팅 정리본

## 2차 온라인 미팅

`meeting2.html`

1차 기록을 불러와 실제 진행 내용, 현장에서 확인한 변화, 수정한 방법과 다음 행동을 정리합니다.

저장 파일:

- `{팀명}_2차미팅.json`: 전체 작업 백업
- `{팀명}_프로젝트발표.html`: 최종 발표회용 독립 HTML

두 앱의 참여 코드는 `KB28`이며 대소문자를 구분하지 않습니다. 작성 내용은 브라우저에 자동 저장되고, 별도 서버로 전송하지 않습니다.
