# 나의 봉사동기 프로필

전국청소년자원봉사대회 교육 프로그램을 위한 학생용 봉사동기 활동입니다.

## 사용하기

이름·학교 입력 → 검사 안내 → 30문항 응답 → 결과 리포트 순서로 진행합니다. 결과를 본 뒤 응답을 수정하고 결과 리포트로 바로 돌아갈 수 있습니다.

`index.html` 하나에 화면, 문항, 채점 로직과 일러스트가 포함되어 있습니다. 파일을 내려받아 브라우저에서 열면 인터넷 연결 없이도 실행됩니다. 빌드나 패키지 설치가 필요하지 않습니다.

## 데이터 처리

앱은 이름, 학교, 응답을 외부로 전송하지 않습니다. 현재 브라우저 탭의 sessionStorage에 임시 보관하며, 새로 시작하기를 누르면 삭제합니다. 별도의 서버, 데이터베이스나 분석 도구를 사용하지 않습니다.

## 결과 해석

Clary et al.(1998)의 Volunteer Functions Inventory(VFI)를 참고한 교육용 활동입니다. 이 한국어 교육판 자체의 신뢰도와 타당도를 별도로 검증한 것은 아닙니다. 각 동기의 다섯 문항에 모두 수치로 응답하면 평균을 표시하며, ‘아직 잘 모르겠어요’는 점수에서 제외하고 해당 동기를 ‘생각 중’으로 표시합니다.
