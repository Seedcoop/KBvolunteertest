# KB AI·바이브코딩 워크숍

봉사 프로젝트 기획을 AI 제작 요청문으로 정리하고, 완성된 페이지를 확인·수정한 뒤 발표를 준비하는 데스크톱 웹앱입니다.

- 처음 접속하면 참여 코드 4글자를 입력합니다. `kb28`은 영문 대소문자를 구분하지 않습니다. 같은 탭의 새로고침에서는 입장 상태를 유지하고, 새 브라우저 세션에서는 다시 입력합니다. 세션 저장이 제한되어도 현재 페이지에서 입장할 수 있습니다.
- 코드를 확인한 뒤 작업 내용 불러오기와 Supabase 전송을 시작합니다. 이 화면은 교육 참여 코드 확인용이며 서버 인증을 대체하지 않습니다. 기존 저장 전용 RPC와 조회 차단 권한은 그대로 적용됩니다.
- `index.html` 하나에 코드·이미지·서체를 포함합니다. 파일을 내려받아 오프라인에서도 입력, 미리보기, 요청문 복사와 백업을 사용할 수 있습니다.
- 생성되는 요청문은 HTML5·CSS3·Vanilla JavaScript, 외부 의존성 금지, `file://` 실행과 정확한 `팀명.html` 파일명을 지정합니다.
- 색상과 시각적 디자인은 별도 무드보드를 첨부하여 지정합니다.
- ‘제작 요청문 복사’를 누르면 그 시점의 팀명·기획·구성·요청문을 기존 Supabase 프로젝트에 저장합니다. 오프라인 복사 기록은 브라우저에 대기시키고 연결이 복구되면 전송합니다.
- 자동 복사가 제한되면 수동 복사 창을 제공합니다. 저장 대기·완료 상태는 화면 아래에서 확인할 수 있습니다.

## 데이터 운영

Supabase Table Editor에서 `public.workshop_prompt_submissions`를 엽니다. `team_name`/`team_key`로 팀별 기록을 조회하고 `created_at`으로 저장 순서를 확인할 수 있습니다. 팀 이름은 수집을 위한 분류값이며 학생 인증 수단은 아닙니다. 같은 팀에서 다시 복사하면 새 이력을 저장하고, 같은 전송의 재시도는 중복 저장하지 않습니다.

| 필드 | 내용 |
| --- | --- |
| `team_name`, `team_key` | 팀 이름과 정규화한 분류값 |
| `project_name`, `project`, `design` | 프로젝트 이름, 질문 답변과 페이지 구성 |
| `prompt` | 복사 시점의 완전한 제작 요청문 |
| `output_filename` | 팀 이름에 `.html`을 붙인 결과물 파일명 |
| `client_created_at`, `created_at` | 복사한 시각과 서버가 받은 시각 |
| `submission_id`, `client_id` | 중복 방지용 이벤트 ID와 임의의 브라우저 ID |

브라우저에는 공개용 publishable key만 포함합니다. 테이블은 RLS와 권한 회수로 직접 조회·입력·수정·삭제를 차단하고, 검증된 저장 전용 RPC만 허용합니다. 관리용 비밀 키는 포함하지 않습니다. `supabase/migrations/202609130001_workshop_collection.sql`이 수집 스키마입니다.

자동 저장은 해당 브라우저를 기준으로 합니다. 컴퓨터를 바꾸기 전 JSON 백업을 저장하십시오. 인터넷이 끊긴 상태에서 브라우저 데이터를 삭제하면 전송 대기 기록도 사라질 수 있으므로 서버 저장 완료를 확인하십시오.

## 검증과 참고

로컬 파일의 오프라인 입력·복사·재열기, 연결 복구 후 실제 Supabase 저장, 이벤트 재시도 중복 방지, 익명 조회 차단을 확인했습니다.

과정은 KB 전국청소년자원봉사대회 최종 운영 자료를 따릅니다. 구조는 [AI_bootcampforyouth](https://github.com/Seedcoop/AI_bootcampforyouth)의 입력→요청문 조립→직접 확인→수정 흐름을 참고했고, 디자인은 KB 프로젝트의 옐로우·크림·Paperlogy 서체를 적용했습니다.
